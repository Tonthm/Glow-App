# Component and Layout

## Purpose

Use this domain for component selection, section composition, layout structure, hero and card patterns, background treatments, hover effects, and product or dashboard UI.

## Source-backed references

- [Aceternity](../websites/aceternity.md): motion and visual-effect components for heroes, cards, backgrounds, and hover states; marked recommended in the sheet for distinctive sections when appropriate.
- [daisyUI](../websites/daisyui.md): base UI components such as buttons, inputs, modals, dropdowns, and forms, with a consistency-oriented note.
- [21st.dev](../websites/21st-dev.md): community sections and components to study and adapt to an existing design system.
- [Origin UI](../websites/origin-ui.md): simple, clean components suited to product and dashboard interfaces.

## Selection rule

Treat these as references to adapt. The sheet does not provide a project design system or implementation requirement.
